# Breeze Café Website – Changelog

This document records the development progress, updates, improvements and functionality added to the Breeze Café website.

## Version 1.0 – Initial Website Development

### Added
- Created the homepage to introduce Breeze Café.
- Developed the About Us page to provide information about the café.
- Created a Menu page to display food and beverage offerings.
- Developed a Reservations page for customer reservation enquiries.
- Created a Contact Us page containing business information and contact details.
- Added navigation links between the website pages.
- Added images to improve the website's visual presentation.

## Version 2.0 – Website Styling and Responsiveness

### Added
- Applied a consistent coffee brown, cream, white and green colour scheme.
- Added typography using Georgia and Open Sans.
- Styled navigation menus, headings, buttons, forms and content sections.
- Added responsive layouts for smaller screens and mobile devices.
- Improved spacing, alignment and readability across the website.

## Version 3.0 – Interactive Website Functionality

### Added
- Implemented an interactive accordion on the About Us page.
- Added JavaScript functionality to expand and collapse the Mission, Vision and Values sections.
- Added menu search functionality to help customers find specific menu items.
- Implemented category filtering for breakfast, light lunches, drinks and desserts.
- Added price sorting functionality to arrange menu items from lowest to highest or highest to lowest.
- Implemented an image lightbox to allow customers to view enlarged menu images.
- Added JavaScript form validation and feedback messages to the Contact page.
- Integrated an interactive location map on the Contact page using Leaflet.js and Esri map tiles.

## Version 4.0 – Visual Improvements and Animations

### Added
- Added scroll reveal animations to the Menu page.
- Implemented hover animations on menu cards and images.
- Added smooth transitions to buttons and interactive elements.
- Improved accordion button hover effects and content animations on the About Us page.
- Added input focus effects to the Contact page form.
- Improved the visual interaction of the Contact page map.
- Added entrance animations to the Reservations page.
- Improved reservation form hover effects and button transitions.

## Version 5.0 – Search Engine Optimisation (SEO)

### Added
- Added a descriptive SEO title to the homepage.
- Added a meta description describing Breeze Café and its services.
- Added relevant meta keywords.
- Added author metadata.
- Added a theme colour metadata tag.
- Improved image alternative text to provide clearer descriptions of website images.

### Planned Improvements
- Apply unique SEO titles and descriptions to all remaining website pages.
- Complete the sitemap.xml and robots.txt files.
- Review heading structures and internal links across all pages.
- Improve website search engine visibility.

## Future Development

### Planned
