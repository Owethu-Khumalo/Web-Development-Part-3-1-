# Breeze Café Website

**A responsive website for Breeze Café – Estcourt, KwaZulu-Natal**

## 1. Project Overview

Breeze Café is a multi-page website developed to establish an online presence for a local café based in Estcourt, KwaZulu-Natal.

The website provides customers with information about the café, its menu, available services, reservation enquiries and contact details. It is designed to offer a welcoming and user-friendly experience while reflecting the café's warm and comfortable atmosphere.

The project focuses on creating an attractive, responsive and functional website using HTML, CSS and JavaScript.

## 2. Project Objectives

The main objectives of the Breeze Café website are to:

- Establish an online presence for Breeze Café.
- Provide customers with information about the café and its offerings.
- Display food, beverages and dessert options.
- Allow customers to submit reservation enquiries.
- Make contact information and location details easily accessible.
- Improve website usability through interactive features.
- Apply responsive design principles for different screen sizes.
- Improve search engine visibility through SEO techniques.

## 3. Website Pages

The website consists of the following pages:

| Page | Description |
|---|---|
| Home | Introduces Breeze Café and highlights its main offerings. |
| About Us | Provides information about the café, including its mission, vision and values. |
| Menu | Displays available meals, drinks and desserts. |
| Reservations | Allows customers to submit reservation requests. |
| Contact Us | Provides contact details, business information, a location map and a contact form. |

## 4. Technologies Used

The following technologies and tools were used during development:

- **HTML5:** Used to structure the website content and pages.
- **CSS3:** Used for styling, layouts, colours, responsiveness, animations and transitions.
- **JavaScript:** Used to implement interactive website functionality.
- **Leaflet.js:** Used to display the interactive location map.
- **Esri World Street Map:** Used as the map tile provider.
- **Visual Studio Code:** Used as the development environment.
- **GitHub:** Used for source code management and version control.

## 5. Website Features and Functionality

### Homepage
- Welcoming introduction to Breeze Café.
- Highlights important café offerings.
- Navigation links to other website pages.
- Links to the menu and reservation pages.

### About Us Page
- Information about the café.
- Mission, vision and values sections.
- Interactive accordion functionality.
- Smooth hover effects and animations.

### Menu Page
- Displays breakfast, light lunches, drinks and desserts.
- Search functionality for menu items.
- Category filtering.
- Price sorting from lowest to highest and highest to lowest.
- Interactive image lightbox for viewing enlarged menu images.
- Scroll reveal animations and hover effects.

### Reservations Page
- Reservation enquiry form.
- Input fields for customer information and reservation details.
- Form styling and interactive focus effects.
- Animated page elements and button transitions.

### Contact Page
- Displays café contact information and location.
- Interactive map showing the café's location in Estcourt.
- Contact form with JavaScript validation and feedback messages.
- Smooth input focus effects and button animations.

## 8. Installation and Setup

To view the Breeze Café website locally:

1. Download or clone the project repository.
2. Extract the project files if downloaded as a ZIP folder.
3. Open the project folder in Visual Studio Code.
4. Ensure the HTML, CSS, JavaScript and Images folders remain in their correct locations.
5. Open `index.html` in a web browser.
6. Navigate through the website using the navigation menu.

For easier local development, the Visual Studio Code Live Server extension can be used to launch the website.
